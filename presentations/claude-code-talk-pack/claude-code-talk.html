13
Three controls · three questions

Plan, /goal and /loop solve different problems.

APPROVED PLAN
HOW?
Evidence→Plan→Approved route

Files · design · scope · tests · risks. Human reviews the route before execution.

/goal
WHEN DONE?
Turn→Evidence→Goal met?NO ↺YES → stop

Condition-driven. Re-check after turns until the measurable finish line holds.

/loop
WHEN AGAIN?
Run→Wait Δt→Run again↺ schedule

Time-driven. Re-run a prompt on an interval while the session stays open.
